# چک‌لیست MVP

پانزده قابلیت MVP طبق بند ۵۹ سند محصول، به‌همراه زیرساخت لازم.

وضعیت را همزمان با پیشرفت کار به‌روز کنید. این فایل مرجع پاسخ به «چقدر مانده؟» است.

## زیرساخت

- [x] اسکلت Next.js 16.3 با TypeScript strict
- [x] دیزاین سیستم RTL با فونت ایران‌سنس‌ایکس و توکن‌های برند
- [x] سیستم مستندات فارسی
- [x] قوانین و پرامپت‌های کرسر
- [x] قفل ماشینی معماری (ESLint boundaries + بررسی ساختار)
- [x] اسکیمای کامل دیتابیس و مایگریشن‌ها
- [x] کتابخانه محاسبات پول، طلا و تاریخ جلالی با تست

## قابلیت‌های MVP

- [x] ۱. ثبت‌نام و ورود با کد یک‌بارمصرف
- [x] ۲. احراز هویت کامل (لایه جدا)
- [x] ۳. پروفایل کودک
- [x] ۴. کاتالوگ محصولات با محور مناسبت
- [x] ۵. موتور قیمت طلا
- [x] ۶. خرید محصول با قیمت‌گذاری شفاف
- [x] ۷. پرداخت (کارت‌به‌کارت + پورت آماده برای درگاه)
- [x] ۸. مدیریت سفارش با ماشین حالت
- [x] ۹. لینک هدیه
- [x] ۱۰. مشارکت در گنجینه بدون نیاز به حساب
- [x] ۱۱. موجودی گنجینه با دفتر کل طلا
- [x] ۱۲. پنل مدیریت
- [x] ۱۳. پیامک
- [x] ۱۴. شخصی‌سازی محصول
- [x] ۱۵. کارت هدیه فیزیکی با QR

## آماده‌سازی انتشار

- [x] صفحات عمومی سایت با روایت برند و سئوی فارسی
- [x] تست‌های دامنه (Vitest) و مسیرهای حیاتی (Playwright)
- [x] Dockerfile و مستندات استقرار
- [x] بکاپ خودکار دیتابیس
- [x] چک‌لیست امنیتی قبل از انتشار

## تعریف «تمام‌شده» برای هر قابلیت

یک قابلیت تمام است اگر:

1. منطق دامنه‌اش تست واحد دارد
2. رابط کاربری فارسی و RTL کامل دارد
3. حالت خطا و حالت خالی طراحی شده
4. دسترسی و مجوزش هم در صفحه و هم در اکشن بررسی می‌شود
5. کارت مستندات ماژول به‌روز است
6. `npm run verify` موفق است
7. `docs/CONTEXT.md` به‌روز شده
