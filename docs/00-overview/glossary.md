# واژه‌نامه پروژه

> **این مهم‌ترین فایل برای جلوگیری از دوباره‌کاری است.**
>
> هر مفهوم دقیقاً **یک** نام فارسی و **یک** نام انگلیسی دارد. نام انگلیسی در کد استفاده می‌شود
> (نام جدول، نام تایپ، نام ماژول) و نام فارسی در رابط کاربری و مستندات.
>
> اگر مفهومی اینجا نیست، **اول اینجا اضافه‌اش کنید، بعد کد بنویسید.**

## مفاهیم هسته

| فارسی | انگلیسی (کد) | تعریف دقیق |
| --- | --- | --- |
| گنجینه | `Treasure` | ظرف دارایی طلای یک کودک. هر کودک می‌تواند بیش از یک گنجینه داشته باشد (مثلاً گنجینه دائمی و گنجینه یک مناسبت خاص). |
| گنجینه رویداد | `EventTreasure` | گنجینه‌ای که به یک مناسبت مشخص و تاریخ‌دار گره خورده است، مثل «تولد پنج‌سالگی آراد». |
| مشارکت | `Contribution` | یک نوبت افزودن ارزش به گنجینه توسط یک نفر. شامل مبلغ، هویت هدیه‌دهنده و پیام او. |
| هدیه‌دهنده | `Contributor` | کسی که به گنجینه مشارکت می‌کند. لزوماً کاربر ثبت‌نام‌شده نیست و **مالک دارایی هم نیست**. |
| لینک هدیه | `GiftLink` | نشانی عمومی و کوتاه که والد برای دعوت دیگران به مشارکت در گنجینه به اشتراک می‌گذارد. |
| کارت هدیه | `GiftCard` | کارت فیزیکی برنددار با QR که مهمان در مراسم به‌دست می‌گیرد و اسکن آن به گنجینه کودک می‌رسد. |
| دفتر کل طلا | `GoldLedger` | دفتر append-only تمام ورود و خروج طلا. **تنها منبع حقیقت موجودی است.** |
| قلم دفتر کل | `GoldLedgerEntry` | یک ردیف در دفتر کل با مقدار (میلی‌گرم)، جهت، منبع و مرجع. |
| پیام یادگاری | `Keepsake` | پیام متنی که هدیه‌دهنده برای کودک می‌گذارد و در گنجینه ماندگار می‌شود. |
| هدف | `Goal` | مقدار طلایی که والد برای گنجینه هدف‌گذاری کرده، به‌همراه مهلت. |
| مایل‌استون | `Milestone` | نقطه عطف قابل جشن گرفتن در مسیر گنجینه (مثلاً «اولین گرم کامل شد»). |
| مناسبت | `Occasion` | رویداد زندگی کودک که خرید حول آن شکل می‌گیرد: تولد، اولین دندان، نوروز، جشن تکلیف و غیره. |
| شخصی‌سازی | `Personalization` | داده‌های اختصاصی‌سازی محصول: نام، تاریخ تولد، تصویر، پیام حکاکی. |

## مفاهیم هویت و مالکیت

> این سه مفهوم **هرگز** نباید یکی گرفته شوند. توضیح کامل در [`../02-domain/domain-rules.md`](../02-domain/domain-rules.md).

| فارسی | انگلیسی (کد) | تعریف دقیق |
| --- | --- | --- |
| کاربر | `User` | یک حساب کاربری با شماره موبایل تاییدشده. |
| کودک | `Child` | پروفایل هویتی کودک. **قهرمان محصول است، ولی مالک قانونی دارایی نیست.** |
| دارنده حساب | `AccountHolder` | کاربر بزرگسالی که حساب و گنجینه به نام او مدیریت می‌شود. |
| مالک دارایی | `AssetOwner` | شخصی که از نظر حقوقی مالک طلاست. در MVP همیشه دارنده حساب است. |
| سرپرست | `Guardian` | رابطه بین یک کاربر و یک کودک (مادر، پدر، پدربزرگ و ...) به‌همراه سطح دسترسی. |
| احراز هویت کامل | `Kyc` | تایید هویت با کد ملی و تاریخ تولد. **جدا از ورود به حساب** و فقط برای عملیات مالی خاص لازم است. |

## مفاهیم مالی

| فارسی | انگلیسی (کد) | تعریف دقیق |
| --- | --- | --- |
| ریال | `rial` | **واحد پایه پول در تمام کد و دیتابیس.** همیشه عدد صحیح. |
| تومان | `toman` | فقط واحد نمایش. ۱ تومان = ۱۰ ریال. هرگز در دیتابیس ذخیره نمی‌شود. |
| میلی‌گرم | `mg` | **واحد پایه وزن طلا در تمام کد و دیتابیس.** همیشه عدد صحیح. |
| گرم | `gram` | فقط واحد نمایش. ۱ گرم = ۱۰۰۰ میلی‌گرم. |
| عیار | `karat` | خلوص طلا: ۱۸ یا ۲۴. در محاسبه ارزش طلای خام دخیل است. |
| طلای خالص معادل | `pureMg` | وزن معادل طلای ۲۴ عیار. مبنای مقایسه و جمع‌زدن طلاهای با عیار متفاوت. |
| قیمت مرجع طلا | `GoldPrice` | قیمت هر گرم طلای خام با عیار مشخص در یک لحظه معین، به‌همراه منبع. |
| اجرت | `makingFee` | دستمزد ساخت زیورآلات. |
| سود فروشنده | `profit` | حاشیه سود فروشگاه. |
| مالیات بر ارزش افزوده | `vat` | مالیات قانونی. |
| حباب | `premium` | تفاوت قیمت سکه یا شمش با ارزش ذاتی طلای آن. |
| قفل قیمت | `PriceLock` | ثبت غیرقابل‌تغییر قیمت در لحظه ثبت سفارش. |
| ریزمحاسبات قیمت | `PriceBreakdown` | تفکیک کامل و شفاف اجزای قیمت که به کاربر نشان داده و در سفارش ذخیره می‌شود. |

## مفاهیم تجارت

| فارسی | انگلیسی (کد) | تعریف دقیق |
| --- | --- | --- |
| محصول | `Product` | یک قلم کالا در کاتالوگ. |
| گونه محصول | `ProductVariant` | نسخه مشخص محصول با وزن، عیار و قیمت خاص خودش. **موجودی روی گونه است، نه محصول.** |
| سبد خرید | `Cart` | سبد موقت کاربر پیش از ثبت سفارش. |
| سفارش | `Order` | خرید نهایی‌شده با قیمت قفل‌شده و ماشین حالت مشخص. |
| قلم سفارش | `OrderItem` | یک ردیف از سفارش با ریزمحاسبات قیمت ذخیره‌شده. |
| پرداخت | `Payment` | تلاش برای پرداخت یک سفارش یا یک مشارکت. |
| رسید کارت‌به‌کارت | `CardTransferReceipt` | مدرکی که کاربر برای پرداخت کارت‌به‌کارت آپلود می‌کند و ادمین آن را تایید یا رد می‌کند. |
| کتابخانه فایل | `File library` | فهرست فایل‌های آپلودی (عکس محصول، کودک، رسید و مشابه) با رکورد در `media_files`؛ بایت فایل روی دیسک است نه داخل دیتابیس. |
| مرسوله | `Shipment` | بسته ارسالی به مشتری. |
| گزارش رخداد | `AuditLog` | ثبت غیرقابل‌تغییر هر عملیات حساس برای حسابرسی. |

## قراردادهای نام‌گذاری در کد

- جدول‌های دیتابیس: انگلیسی، `snake_case`، **جمع** (`gold_ledger_entries`, `gift_links`)
- ستون‌ها: انگلیسی، `snake_case` (`created_at`, `amount_rial`)
- تایپ‌ها و کلاس‌ها: `PascalCase` (`TreasureSummary`)
- توابع و متغیرها: `camelCase` (`calculateOrderTotal`)
- ثابت‌های سراسری: `SCREAMING_SNAKE_CASE`
- نام فایل‌ها: `kebab-case` (`gold-ledger.repo.ts`)
- **ستون‌های پولی حتماً پسوند `_rial` دارند** (`total_rial`)
- **ستون‌های وزنی حتماً پسوند `_mg` دارند** (`weight_mg`)
- **ستون‌های زمانی حتماً پسوند `_at` دارند و epoch میلی‌ثانیه‌اند** (`created_at`)

## واژه‌هایی که استفاده نمی‌کنیم

| ننویسید | بنویسید | چرا |
| --- | --- | --- |
| `wallet` / کیف پول | `treasure` / گنجینه | «کیف پول» حس فین‌تک می‌دهد و با هویت برند نمی‌خواند |
| `investment` / سرمایه‌گذاری | `treasure` / گنجینه | ما اپلیکیشن سرمایه‌گذاری نیستیم |
| `donation` / اهدا | `contribution` / مشارکت | این خیریه نیست |
| `balance` / موجودی حساب | `goldBalance` / موجودی طلا | موجودی همیشه به وزن است نه پول |
| `price` تنها | `priceRial` | واحد باید در نام باشد |
| `weight` تنها | `weightMg` | واحد باید در نام باشد |
