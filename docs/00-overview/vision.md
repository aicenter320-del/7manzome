# چشم‌انداز محصول

## جمله‌ای که کل پروژه را توضیح می‌دهد

هفت منظومه یک طلافروشی آنلاین تخصصی کودکان است که به والدین و اطرافیان کودک اجازه می‌دهد
به‌جای خرید هدایای مصرفی، طلا را در قالب زیورآلات، سکه، شمش و محصولات شخصی‌سازی‌شده برای کودک
خریداری کنند و به مرور یک «گنجینه طلای شخصی» برای او بسازند.

**شعار:** هر هدیه، یک قدم برای ساختن گنجینه او.

## ایده مرکزی

ما نمی‌گوییم «طلای کودک بخرید». می‌گوییم:

> برای آینده فرزندت یک گنجینه بساز.

و این گنجینه از مسیرهای متعدد ساخته می‌شود: پدر، مادر، پدربزرگ، مادربزرگ، عمو، خاله، دایی، دوستان خانواده.
هرکس سهم کوچکی دارد و مجموع این سهم‌های کوچک یک دارایی واقعی می‌سازد.

## پنج مسئله‌ای که حل می‌کنیم

1. **انتخاب هدیه سخت شده است.** کودک اسباب‌بازی دارد، لباس را دوست ندارد. هدیه‌ای می‌دهیم که هم ارزش احساسی دارد و هم اقتصادی.
2. **هدیه‌های کوچک پراکنده هدر می‌روند.** بیست مهمان با مبالغ کوچک، در مجموع می‌توانند یک دارایی معنادار بسازند. ما این پول‌های خرد را به طلا تبدیل می‌کنیم.
3. **طلای کودک همیشه کاربردی نیست.** انگشتر و پابند برای هر سنی مناسب نیست؛ سکه اختصاصی با نام و تصویر کودک، ترکیب دارایی و خاطره است.
4. **نگهداری طلا دردسر دارد.** سرقت، گم شدن، اصالت، فروش مجدد.
5. **اعتماد در بازار طلا کمیاب است.** پاسخ ما شفافیت کامل قیمت است: وزن، عیار، ارزش طلای خام، اجرت، سود، مالیات — همه نمایش داده می‌شود.

## پنج تفاوت بنیادی با طلافروشی آنلاین معمولی

| طلافروشی معمولی | هفت منظومه |
| --- | --- |
| «چه طلایی می‌خواهی بخری؟» | «برای چه کسی، چه مناسبتی و با چه هدفی؟» |
| محصول‌محور | کودک‌محور |
| یک خریدار | شبکه خانواده |
| تراکنش | رابطه |
| طلا به‌عنوان کالا | طلا به‌عنوان هدیه + خاطره + گنجینه |

## سه لایه‌ای که نباید قاطی شوند

بزرگ‌ترین ریسک این پروژه پیچیدگی بیش از حد محصول است. پس:

- **امروز:** فروشگاه طلای کودک
- **فردا:** گنجینه طلا + سیستم هدیه
- **آینده:** اکوسیستم طلای خانواده

آنچه کاربر می‌بیند: یک طلافروشی زیبا و تخصصی کودکان.
آنچه واقعاً می‌سازیم: یک پلتفرم گنجینه طلای کودک.

## تصمیم مهم تجربه کاربری

معیار اصلی نمایش باید **وزن طلا** باشد، نه مبلغ:

```
🪙 ۳.۲ گرم طلای گنجینه آراد
   ارزش امروز: ۵۲ میلیون تومان
```

اگر مبلغ قهرمان صفحه شود، ما به یک اپلیکیشن سرمایه‌گذاری تبدیل می‌شویم و هویت کودک‌محور برند از بین می‌رود.

- معیار اصلی: وزن طلا (گرم)
- معیار ثانویه: ارزش ریالی

## معیار شمال (North Star)

**مقدار طلای ذخیره‌شده برای کودکان.**

نه درآمد، نه تعداد کاربر. این عدد است که داستان برند را می‌سازد:
«تا امروز خانواده‌های هفت منظومه ۲۸۴ کیلو طلا برای آینده کودکانشان ساخته‌اند.»

## دو حلقه رشد

**حلقه ویروسی:** والد گنجینه می‌سازد ← لینک هدیه را می‌فرستد ← فامیل هدیه می‌دهد ← فامیل با برند آشنا می‌شود ← خودش برای فرزندش گنجینه می‌سازد.

**حلقه عادت:** هدف تعریف می‌شود ← خرید کوچک طلا ← پیشرفت افزایش می‌یابد ← مایل‌استون ← اعلان ← پاداش احساسی ← خرید بعدی.

هدف این نیست که کاربر هر روز اپلیکیشن را باز کند؛ هدف این است که والد در طول سال چندین بار طبیعی به گنجینه کودک فکر کند.
