# مستندات پروژه هفت منظومه

این پوشه «منبع حقیقت» پروژه است. هر تصمیم معماری، هر ماژول و هر قانون دامنه اینجا ثبت می‌شود.

> قانون طلایی: **کد بدون مستند، و مستند بدون کد، هر دو باگ محسوب می‌شوند.**
> اگر کدی نوشتید که با این مستندات نمی‌خواند، یا مستند را اصلاح کنید یا کد را.

## از کجا شروع کنم؟

اگر تازه وارد پروژه شده‌اید (انسان یا عامل هوش مصنوعی)، به این ترتیب بخوانید:

1. [`CONTEXT.md`](CONTEXT.md) — وضعیت **همین الان** پروژه. چه چیزی ساخته شده، چه چیزی نه.
2. [`00-overview/vision.md`](00-overview/vision.md) — چرا این پروژه وجود دارد.
3. [`00-overview/glossary.md`](00-overview/glossary.md) — واژه‌نامه. **بدون خواندن این، نام‌گذاری‌ها را اشتباه می‌کنید.**
4. [`01-architecture/overview.md`](01-architecture/overview.md) — لایه‌بندی و قوانین وابستگی.
5. [`01-architecture/module-registry.md`](01-architecture/module-registry.md) — فهرست ماژول‌ها. **قبل از ساخت هر چیز جدید اینجا را چک کنید.**
6. [`02-domain/domain-rules.md`](02-domain/domain-rules.md) — قوانین غیرقابل‌مذاکره دامنه (پول، طلا، مالکیت).

## نقشه پوشه‌ها

| پوشه | محتوا |
| --- | --- |
| `00-overview/` | چشم‌انداز، پرسوناها، واژه‌نامه |
| `01-architecture/` | لایه‌بندی، ساختار پوشه، رجیستری ماژول‌ها، قراردادهای کدنویسی |
| `02-domain/` | مدل داده، ERD، ماشین‌های حالت، قوانین دامنه |
| `03-modules/` | یک کارت مستند برای هر ماژول |
| `04-ui/` | دیزاین سیستم، توکن‌ها، قوانین RTL و زبان فارسی |
| `05-ops/` | متغیرهای محیطی، استقرار، بکاپ، امنیت عملیاتی |
| `06-decisions/` | ADRها؛ تصمیم‌های معماری با دلیل و پیامد |
| `07-roadmap/` | فازها، چک‌لیست MVP، تاریخچه تغییرات |

## چه زمانی چه چیزی را به‌روز کنم؟

| کاری که کردید | چه چیزی باید به‌روز شود |
| --- | --- |
| ماژول جدید ساختید | `01-architecture/module-registry.md` + یک فایل در `03-modules/` |
| جدول یا ستون دیتابیس اضافه کردید | `02-domain/data-model.md` + `02-domain/erd.md` + `05-ops/seed-catalog.md` + `scripts/seed/registry.ts` |
| قانون مالی یا محاسباتی تغییر کرد | `02-domain/domain-rules.md` |
| تصمیم معماری گرفتید | یک ADR جدید در `06-decisions/` |
| فیچری از رودمپ تمام شد | `07-roadmap/mvp-checklist.md` + `CONTEXT.md` |
| کامپوننت UI مشترک اضافه کردید | `04-ui/design-system.md` |
| متغیر محیطی اضافه کردید | `05-ops/environment.md` + `.env.example` |

**در پایان هر تسک، `CONTEXT.md` همیشه باید به‌روز شود.** بدون استثنا.
