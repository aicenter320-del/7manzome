# ADR-0011: Liquid Glass روشن طلایی

**وضعیت:** پذیرفته
**تاریخ:** ۱۴۰۵-۰۵-۲۲

## زمینه

ظاهر MVP تخت و کاغذگرم بود. هدف برند «لوکس خانوادگی» است و رابط باید اعجاب‌آور
باشد، بدون اینکه تم تیره یا پر کردن صفحه با طلا حس فروشگاه اسباب‌بازی یا پنل بانک
بدهد.

## گزینه‌ها

۱. شیشهٔ خالص CSS بدون موتور شکست نور
۲. کتابخانهٔ ۳بعدی (Three.js / WebGL جدا)
۳. موتور [website-glass](https://websiteglass.com/) به‌صورت سورس در `shared/ui` با
   تم روشن طلایی و بدون دارک‌مود

## تصمیم

گزینه ۳.

- موتور لنز (`Glass` / `GlassSurface` / `GlassButton`) در `src/shared/ui/` می‌ماند؛
  پوشهٔ `src/components/` ساخته نمی‌شود.
- تم فقط روشن است. `<html class="light">` تا موتور شیشه به `prefers-color-scheme`
  تیره اعتماد نکند.
- طلا لهجه است: بردر گرادیانی، سایهٔ رنگی، دیسک آیکون. پر کردن سطح با طلا ممنوع است.
- لنز کامل فقط روی سطوح شاخص (هدر کپسولی، دیسک آیکون).
- کارت، جدول و پنل‌های سرور با کلاس CSS `.glass` غنی (درخشش و سایهٔ لبه).
- سطوح شناور (دیالوگ، سلکت، دراپ‌داون، پاپ‌اور، تولتیپ، شیت) با `GlassSurface`.

## دلیل

سورس داخل مخزن مالکیت را نگه می‌دارد، با Tailwind v4 و React 19 سازگار است، و در
Safari/Firefox به بلور ساده برمی‌گردد. تم روشن خوانایی فارسی و حس کاغذ گرم برند را
حفظ می‌کند.

## پیامدها

آسان‌تر: یک زبان بصری برای سایت، داشبورد و ادمین؛ آیکون‌های عملیاتی یکدست.

سخت‌تر: لنز روی Chromium واقعی است؛ موبایل کم‌قدرت باید با `.glass` CSS و
`prefers-reduced-transparency` آرام بماند.
