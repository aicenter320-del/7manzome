# ADR-0017: نوار night برای هیرو و CTA پایانی خانه

**وضعیت:** پذیرفته
**تاریخ:** ۱۴۰۵-۰۵-۲۷

## زمینه

پالت ویترین کرم و شامپاین است ([ADR-0014](0014-luxury-cream-palette.md)) و سایت تم تیره
ندارد. الگوی خانهٔ صورت‌فلکی برای هیرو و شعار پایانی به سطح شب‌منظومه‌ای نیاز دارد
تا استیکر کودک و ستاره‌ها خوانا باشند، بدون دارک‌مود سراسری.

## گزینه‌ها

۱. کل مسیر مشتری را تیره کردن
۲. همان کرم برای هیرو؛ استیکر روی کاغذ روشن
۳. فقط هیرو، نوار قیمت، هدر مشتری و CTA پایانی روی توکن `--night`؛ بقیه کرم

## تصمیم

گزینه ۳.

- توکن‌های `--night` / `--night-mid` / `--night-lift` / `--night-foreground` فقط برای
  این نوارها.
- کاغذ خانه کرم (`--cream`)؛ کارت‌ها سفید.
- دکمهٔ `gold` گرادیان طلا + درخشش شیشه است؛ سکشن صفحه با طلا پر نمی‌شود مگر کارت دعوت هدیه.
- `/admin` عوض نمی‌شود.

## دلیل

صورت‌فلکی روی کرم محو می‌شود. محدود کردن night به نوارهای خانه، حس منظومه را می‌دهد
بدون نقض «سایت فقط روشن است».

## پیامدها

آسان‌تر: هیرو و شعار پایانی یک زبان دارند.

سخت‌تر: هدر مشتری تیره است حتی روی صفحات کرم (ورود، داشبورد).
