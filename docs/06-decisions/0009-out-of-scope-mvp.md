# ADR-0009: قابلیت‌های عمداً خارج از MVP

**وضعیت:** پذیرفته

## زمینه

سند محصول ایده‌های زیادی دارد. بزرگ‌ترین ریسک این پروژه ساخته‌نشدن سایت خوب نیست؛
بزرگ‌ترین ریسک این است که محصول آن‌قدر پیچیده شود که هرگز منتشر نشود.

این ADR وجود دارد تا **دلیل نساختن** ثبت شود و شش ماه بعد کسی فکر نکند فراموش شده‌اند.

## قابلیت‌های به تعویق افتاده

| قابلیت | چرا الان نه | آمادگی مدل داده |
| --- | --- | --- |
| فروش و بازخرید طلا از کاربر | نیازمند بررسی حقوقی و مدل تسویه | `direction = 'out'` و `source = 'redemption'` پیش‌بینی شده |
| موجودی طلای دیجیتال به‌عنوان مالکیت حقوقی | مدل حقوقی روشن نیست | تفکیک مالکیت در [ADR-0006](0006-ownership-separation.md) انجام شده |
| طلای آب‌شده | نیازمند بررسی عملیاتی و حقوقی | `products.kind` قابل توسعه است |
| مارکت‌پلیس هدیه کودک | تمرکز محصول را از بین می‌برد | — |
| Gold Cashback و شبکه شرکا | فاز سه؛ نیازمند شریک تجاری | — |
| گیمیفیکیشن پیچیده (streak، چرخ شانس) | سایت نباید شبیه بازی شود | مایل‌استون‌ها به‌عنوان نسخه ظریف پیاده می‌شوند |
| اپلیکیشن نیتیو | وب‌اپ کافی است | منطق در `service/` است، افزودن API بعداً کم‌هزینه |
| پیام ویدیویی برای کودک | حجم فایل و هزینه ذخیره‌سازی | پیام متنی یادگاری پیاده می‌شود |
| کد تخفیف و کمپین | فعلاً لازم نیست | ستون `discount_rial` در سفارش موجود است |
| خرید دوره‌ای خودکار طلا | فاز دو | — |
| صفحه اختصاصی کودک (Treasure Dashboard) | فاز دو | — |

## اصل حاکم

سه لایه را جدا نگه می‌داریم:

- **امروز:** فروشگاه طلای کودک
- **فردا:** گنجینه طلا + سیستم هدیه
- **آینده:** اکوسیستم طلای خانواده

## قاعده افزودن دوباره

هر کدام از این‌ها که خواست به دامنه برگردد، نیازمند یک ADR جدید است که توضیح دهد
چه چیزی تغییر کرده و چرا حالا وقتش است.
