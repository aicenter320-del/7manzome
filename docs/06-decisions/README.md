# تصمیم‌های معماری (ADR)

هر تصمیم معماری مهم اینجا با شماره، زمینه، تصمیم و پیامدهایش ثبت می‌شود.

**چرا این کار را می‌کنیم؟** شش ماه بعد، کسی (شاید خودتان) می‌پرسد «چرا این‌طور ساخته شده؟»
بدون ADR، جواب گم می‌شود و تصمیم دوباره باز می‌شود — و این بزرگ‌ترین منبع دوباره‌کاری است.

**تاریخ:** ...

## پیامدها
