# ماژول: هویت (`identity`)

**وضعیت:** ✅ کامل

## مسئولیت

ورود کاربر با کد یک‌بارمصرف پیامکی، مدیریت پروفایل، نقش‌ها و احراز هویت کامل.

مسئول **نیست** برای: پروفایل کودک (آن در `children` است)، و مجوزدهی سطح صفحه
(زیرساخت آن در `server/auth` است).

## API عمومی

```ts
export { requestOtp, verifyOtp, logout, updateProfile, submitKyc } from "./actions/...";
export { getUserById, getUserByPhone } from "./service/user.service";
export type { PublicUser, KycStatus } from "./domain/types";
```

## جدول‌های دیتابیس

`users`، `user_roles`، `otp_codes`، `sessions`، `audit_logs`

## وابستگی‌ها

`notifications` — برای ارسال پیامک کد یک‌بارمصرف.

## قوانین دامنه

- کد یک‌بارمصرف **هرگز به‌صورت متن خام ذخیره نمی‌شود**؛ فقط هش HMAC آن.
- حداکثر ۵ تلاش تایید برای هر کد؛ پس از آن کد سوخته می‌شود.
- محدودیت نرخ: حداکثر ۳ درخواست کد در ۱۰ دقیقه برای هر شماره.
- ورود به حساب **نیازی به احراز هویت کامل ندارد**. این دو مفهوم جدا هستند.
- شماره موبایل ایرانی: ۱۱ رقم با شروع `09`.
- کد ملی با الگوریتم رقم کنترلی اعتبارسنجی می‌شود، نه فقط طول آن.

## مسیرها

- `app/(auth)/login` — ورود دو مرحله‌ای
- `app/(dashboard)/dashboard/profile` — پروفایل و احراز هویت

## نقاط باز

- تایید کد ملی با سرویس رسمی استعلام (فعلاً فقط اعتبارسنجی الگوریتمی).
